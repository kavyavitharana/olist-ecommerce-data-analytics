Olist E-Commerce Data Analytics with SQL and Excel

Project Overview

This project focuses on analysing the Brazilian Olist E-Commerce Public Dataset to identify meaningful business insights related to sales, customer orders, product performance, payment methods, and delivery performance.

The project uses SQL for data querying and analysis, and Microsoft Excel for data cleaning, analysis, and visualization.

Tools & Technologies

- MySQL: Data querying and analysis
- Microsoft Excel: Data analysis and visualization
- Power Query: Data cleaning and data transformation
- PivotTables: Summarizing and analysing data
- PivotCharts: Visualizing business insights

Key Business Insights

- Total Orders: The dataset contains 99,441 customer orders.
- Delivery Rate: 97.02% of all orders were successfully delivered.
- On-Time Delivery: 91.89% of delivered orders arrived on or before the estimated delivery date.
- Top Product Category: Beauty & Health generated the highest product revenue, approximately R$1.26 million.
- Payment Preference: Credit cards accounted for 78.33% of the total payment value.
- Average Order Value: R$160.99.
- Monthly Trend: November 2017 recorded the highest order volume, with 7,544 orders.

Project Files

- `Olist_Ecommerce_Data_Analytics.xlsx` – Excel workbook containing the analysis, PivotTables, charts, and project summary.
- `Olist_Analytics_Queries.sql` – SQL queries used to analyse the dataset.

Dataset

Brazilian Olist E-Commerce Public Dataset.

Project Limitations

- Product revenue is calculated using product prices and excludes freight charges.
- The 2018 monthly order data is incomplete, so full-year comparisons for 2018 may not be reliable.
- Review analysis was not included in the final SQL analysis due to an incomplete data import.
